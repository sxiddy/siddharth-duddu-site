AI video editorIt's a Wrap

Turning hours of event footage into a short aftermovie usually takes an editor several days. An AI agent tool (MCP server) that reads a Google Drive folder of clips and watches every shot. Built with TypeScript, Next.js, Remotion, FFmpeg, Local LLM, MCP, Docker. A complete, music-synced aftermovie from a single Drive link, in minutes instead of days. The live site is in private beta and the code is private, so a demo is available on request.

Real-time watch partyBack Row

When friends watch a movie together online, everyone's video drifts out of sync within minutes. Rooms you join with a link or QR code, with no sign-up and no install. Built with JavaScript, Python, Real-time sync, HTML, CSS. Live on Vercel, with 49 automated tests passing.

Attendance that cannot be fakedProxyProof

Roll calls waste class time, and sign-in sheets let students mark friends present. An Android app where the teacher's phone broadcasts a Bluetooth code that changes every 5 seconds. Built with Kotlin, Android, Bluetooth LE, TypeScript, Python. Screenshots, forwarded codes and a friend's phone all fail. Downloadable APK plus a working demo. The demo may take about 30 seconds to wake up. Demo login is in the GitHub README.
